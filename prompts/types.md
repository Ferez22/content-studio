# Motion types
Selection table for motion-video P1. Content type (content-types.md, "Formats per type") narrows the list, then pick here,
then check ratio/duration vs platforms.md.
Every type prompt = prompts/mine/studio-base.md + the type file. Several deliverables -> one pick each.

| type | prompt | use when | default |
|---|---|---|---|
| product film | [studio-product-film](mine/studio-product-film.md) | awareness, launch hero, brand ad; real UI exists | 15 s, 16:9 / 9:16 |
| launch / announcement | [studio-launch-hype](mine/studio-launch-hype.md) | new feature/offer, event, milestone | 15-20 s, 9:16 |
| launch story | [studio-launch-story](mine/studio-launch-story.md) | product/tool launch told as a story: moment, obstacle, reveal, 2 use cases, VO | 35-40 s, 16:9 / 9:16, VO |
| explainer | [studio-explainer](mine/studio-explainer.md) | educational, how it works, pillar content | 30-45 s, 9:16 / 16:9, VO |
| ad with real footage | [studio-ugc-ad](mine/studio-ugc-ad.md) | boosted ad, leads, social proof; owned clips exist | 15-20 s, 9:16 / 4:5, subtitles |
| single UI moment | [studio-ui-moment](mine/studio-ui-moment.md) | feature highlight, loop, carousel cover | 5-8 s, 1:1 / 4:5 |

Rules:
- No owned clips -> never studio-ugc-ad. No real UI/assets -> explainer or launch-hype (type-led).
- Launch: short beat-driven, no story -> launch-hype; narrated with use cases + VO -> launch-story.
- Boosted -> hook <3 s, subtitles, 2 hook variants.
- New type needed -> propose a new studio-<type>.md to the owner, never improvise one silently.
- Sources of inspiration: prompts/motion/ (creator-owned, see index.md). Never paste their text into ours.
