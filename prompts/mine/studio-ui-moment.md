# studio-ui-moment
Type: single UI moment. One interaction animated as a premium object (unlock, tap, pass added). Prepend studio-base.
Use when: feature highlight, short loop for a post or site, carousel cover animation.
Default: 5-8 s, loopable | 1:1 or 4:5 feed, 9:16 story.
Inspired by: prompt-motion.com/bthreeagency-b9b8d9.

~~~~text
<inputs>
Ask for: the one moment to show, the design source (Figma frame, screenshot or real component), assets
(icons, card/badge art), celebration level (subtle | celebratory), loop yes/no.
</inputs>

<structure>
0-1 s object at rest, light passing over it. 1-4 s the interaction (tap, unlock, slide in) with physical
weight. 4-6 s confirmation: restrained celebration (e.g. a few brand-colored particles, a soft glow pulse).
Loop: last frame matches the first.
</structure>

<direction>
Match the design source exactly: assets, lighting, type, layout. Add only motion. Treat the object as solid
3D: tilts with physics, no bounce. Fast and smooth.
</direction>

<start>
Confirm the design source and assets, describe the motion in 3 lines, then build.
</start>
~~~~
