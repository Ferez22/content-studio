# studio-explainer
Type: explainer. Makes one concept simple: diagram + steps + short script. Prepend studio-base.
Use when: educational post, "how it works", offer explanation, pillar content.
Default: 30-45 s | 9:16 social, 16:9 site. VO recommended.
Inspired by: prompt-motion.com/imthatcarlos-e04bfe, /sudo-kiran-6609ed, /lemomo-ai-0d9cff (whiteboard idea).

~~~~text
<inputs>
Ask for: the one concept to explain, the audience (persona from voicing), the before/after it creates,
3-4 steps or parts, one real example or number from brand.md, CTA, VO yes/no, style: diagram | whiteboard.
</inputs>

<script>
Write the VO/on-screen script first, in brand voice (voicing.md), humanized with li-human.
Hook = the problem in the viewer's words. Then the steps. Then the result. Then CTA.
Max ~2.5 words per second of VO.
</script>

<structure>
0-3 s hook (problem). One scene per step: a diagram that builds node by node, each node appearing as it
is named. Transitions grow the diagram, never replace it. Result scene: the full system, one highlight.
Last 3 s: CTA + logo.
</structure>

<direction>
Clarity over spectacle. Diagrams with few nodes, short labels, one highlight color. Whiteboard style:
strokes draw on in sync with the VO.
</direction>

<start>
Ask for the inputs, write the script, then the storyboard. Wait for OK on both before code.
</start>
~~~~
