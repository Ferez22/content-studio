## Context

In a due diligence, the first days go into reading. A data room can hold hundreds of contracts, financial statements and reports. Analysts open each file, copy key figures into a spreadsheet and only then start the work that needs their judgement.

This demo shows how an agent takes over that first pass.

## Approach

- **Reads the whole data room.** The agent opens every PDF, spreadsheet and scanned document and sorts them by type: contracts, financials, corporate documents.
- **Extracts the key facts.** Revenue, margins, debt, contract terms, change of control clauses and expiry dates go into one structured table.
- **Links every figure to its source.** Each number points to the file and page it came from, so an analyst can check it in one click.
- **Flags what is missing or inconsistent.** Missing years, figures that do not add up and unusual clauses are listed for review.
- **Drafts, never decides.** The agent writes a first draft of the report. An analyst reviews, corrects and approves it.

## Result

The agent produces a first draft report in hours rather than days. Analysts spend their time on the findings, not on the reading. Because every figure is linked to its source, the review is faster and the report is easier to defend.
