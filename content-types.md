# Content types
Why we publish, independent of platform and format. Every brief picks exactly one type.
Order of choice: type (why) -> platform (where, platforms.md) -> format (how, table below).
Brand voice for all: voicing.md + brands/<b>/voicing.md. Strategy per brand (which types work): brands/<b>/strategie.md.

## Types
| type | goal | funnel | proof required | CTA |
|---|---|---|---|---|
| news | react to a sector event + our take | awareness | source URL + date, <= 7 days old; key claim checked in 2nd source | soft (follow, read more) |
| progress | show momentum: project shipped, client, partnership, milestone, new feature | trust | real fact, client OK if named | soft or contact |
| educational | teach something usable now: how-to, method, checklist, framework | awareness, trust | correct steps, tested by us if possible | save, follow, newsletter |
| informative | explain what/why: concept, trend, data, comparison | awareness | sourced data, date of data | read more, follow |
| promotional | sell: offer, launch, service, event, discovery call | conversion | real offer terms, price/limits if stated | one hard CTA |
| case-study | problem -> solution -> measured result for one client | consideration | client OK, real numbers, before/after | contact, book a call |
| opinion | take a clear position on a sector question | awareness, trust | argument + example; no fake data | discuss (comment) |
| story | behind the scenes, founder story, team, lesson learned | trust | true story, people OK to appear | soft |

Educational vs informative: educational = reader can DO something after. Informative = reader KNOWS something after.

## Structure per type
- news: hook = the event in 1 line -> what happened (facts, source) -> what it means for our audience -> our take -> soft CTA.
- progress: result first -> context (who, what) -> how we did it (1-2 points) -> what's next.
- educational: problem the reader has -> steps (3-7, one idea each) -> example -> summary -> save/follow.
- informative: question -> short answer -> explanation with 1-3 data points -> implication for the reader.
- promotional: pain -> offer -> proof -> terms -> one CTA.
- case-study: client + context -> problem (cost of it) -> what we built -> result in numbers -> quote -> CTA.
- opinion: the claim in line 1 -> why (2-3 arguments) -> counter-argument handled -> invite debate.
  What-if variant: hypothesis or personal deduction, labelled ("What if...", "My guess:") -> reasoning -> open question
  that invites disagreement. Never presented as fact.
- story: moment -> tension -> what happened -> lesson -> link to what we do (light).

## Rules
- Never invent: news, numbers, clients, quotes, results. Missing proof -> ask the owner or change type.
- News sourcing: WebSearch, then Firecrawl (firecrawl_search / firecrawl_scrape, paid, cost gate per CLAUDE.md Tools)
  to read the source in full. Keep source URL + date in the deliverable.
- Promotional share: max ~1 in 5 pieces per brand unless strategie.md says otherwise.
- Same idea can feed several formats (article -> posts -> carousel -> motion): plan derivatives in content-studio P2.
