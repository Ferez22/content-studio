# P1 Brief
## Post plan (EVERY post, both modes, before any hook or draft)
Never write a post that has no plan. Start from the idea, refine it, check it against the goal.
1. Idea: raw, in the owner's words. No idea -> 3 proposals from brands/<b>/ideas.md + strategie.md pillars, the owner picks.
2. Refine: key message in 1 sentence = what the reader gets (knows, can do, feels) after reading.
3. Goal: ONE of awareness | trust | debate | leads | sale + success sign (comments, DMs, saves, clicks, calls).
4. Why: why we write this, why now, why us (trigger: client question, result, event, lesson, belief).
   No real reason -> say so, propose to drop or park it in ideas.md.
5. Target: segment/persona from brands/<b>/voicing.md, their situation, their pain or desire in their words
   (knowledge/sales/desire-map.md).
6. Fit check, each yes/no + 1 line: idea serves the goal for this target | type (content-types.md) fits the goal |
   proof exists for every claim | CTA matches the goal | not a repeat of a recent post (ideas.md, campagnes/) |
   promotional share ok (max ~1 in 5). Any no -> refine the idea or change goal/type, state what changed, re-check.
7. Then: angle (1 line), type, pillar, platforms, language + register, CTA.
Write it in brief.md (templates/brief.md "Post plan"). Gate: show the plan to the owner in their chat language (7 short lines) + decisions.
OK -> decisions.md, then hooks. "Go fast" -> plan still written and shown first; assumptions marked [assumed].

## 01q Quick (single post)
1. Post plan (above). Defaults from voicing/strategie/memory; ask only gaps (batched, max 3 questions).
2. brief.md Status: draft (DRAFT if voicing draft, TEST if test mode).
3. Plan OK -> 04-production.md (text only).

## 01 Full
0. Post plan steps 1-6 for the campaign as a whole (idea, key message, goal, why, target, fit check).
1. Ask in one batch (offer defaults from strategie.md + memory, the owner confirms or edits):
   goal (awareness|trust|leads|conversion|ad) | type | pillar | format(s) (text|carousel|motion|Higgsfield video|reel)
   | platforms | boost y/n | language | CTA | deadline | credit budget (EUR) | proof available.
2. Boost = yes -> mandatory: burned subtitles, hook < 3s, 2 A/B hook variants, royalty-free music, platform ad rules
   (Meta / LinkedIn ads policies: claims, before/after, personal attributes).
3. Check proof vs type (content-types.md). Missing proof for a case-study or number -> change type or ask.
4. Write brief.md (templates/brief.md full). Create campaign folder + decisions.md (templates/decisions.md).
Gate 1: summary to the owner in their chat language (5 lines: idea, type, formats, platforms, budget) + decisions needed. OK -> decisions.md,
commit "<brand>: brief <slug>".
