# P2 Strategy (full mode)
1. Single piece or series. Series -> number of pieces, rhythm, arc (each piece stands alone).
2. Angle: one sentence, from voicing pillars + desire map (knowledge/sales/desire-map.md): the outcome the reader wants.
3. Hooks: 3 per lead piece (li-post hooks.json formulas for EN; native French for FR; viral-video-writing rules for
   video). Each < 140 chars (LinkedIn) / < 125 (IG) / < 3s spoken (video).
4. Derivatives map (content-types.md "Formats per type"): lead format -> others. Example: motion video -> LinkedIn
   post + IG Reel + X clip + carousel. Brand voicing may require one variant per platform.
5. Calendar: date + platform per piece. Never more than 1 promotional in 5.
   Each piece gets its own post plan line (key message | goal | why | target) in plan.md; fit check per piece.
6. Write plan.md (templates/plan.md), Status: draft.
Gate 2: plan summary in chat language (angle, hooks, pieces + dates) + decisions. OK -> decisions.md, plan Status validated, commit.
